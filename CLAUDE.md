This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

`hello` is a minimal R package generated from the RStudio package template. It exports a single function, `hello()` (`R/hello.R`), which prints "Hello, world!". `DESCRIPTION` still contains template placeholder values (Title, Authors, Description, License).

## Commands

Run from the package root in R (the `.Rproj` is configured with `PackageUseDevtools: Yes`):

```r
devtools::load_all()   # load package for interactive development
devtools::document()   # regenerate docs/NAMESPACE via roxygen2
devtools::install()    # install (RStudio: Ctrl+Shift+B)
devtools::check()      # R CMD check (RStudio: Ctrl+Shift+E)
devtools::build()      # build source tarball
```

From a shell: `R CMD build .` then `R CMD check hello_0.1.0.tar.gz`.

There is no `tests/` directory yet. If tests are added with testthat (`usethis::use_testthat()`), run all with `devtools::test()` and a single file with `devtools::test(filter = "<name>")` or `testthat::test_file("tests/testthat/test-<name>.R")`.

## Architecture notes

- **Exports are pattern-based, not roxygen-managed.** `NAMESPACE` uses `exportPattern("^[[:alpha:]]+")`, so every function whose name starts with a letter is automatically exported. Prefix internal helpers with `.` to keep them private.
- **Docs are hand-written Rd.** `man/hello.Rd` is not generated by roxygen, and `R/hello.R` uses plain `#` comments, not `#'` roxygen blocks. Although the `.Rproj` enables roxygenize (`rd,collate,namespace`), roxygen2 will not overwrite files it didn't generate. To switch to roxygen, add `#'` blocks and delete `NAMESPACE`/`man/hello.Rd` so `devtools::document()` can regenerate them — otherwise edit the `.Rd` files by hand when function signatures change (`R CMD check` flags mismatches).
- `inst/hello_0.1.0.tar.gz` (untracked) is a built tarball placed inside `inst/`; anything in `inst/` gets bundled into the installed package, so build outputs should not live there.
